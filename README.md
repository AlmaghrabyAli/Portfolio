## 📌 Overview

This is the personal portfolio of **Almaghraby Ali Abdalshafy**, a passionate **Full-Stack Developer** specializing in building scalable web applications with **React** and **ASP.NET Core**.

The portfolio showcases real-world projects, structured technical training (DEPI, ITI, NTI), competitive programming experience (ECPC), and a fully functional contact system. It is designed to be lightweight, fast, accessible, and optimized for search engines (SEO).

---

## ✨ Key Features

- 🌓 **Dark & Light Mode:** Seamless theme switching with system preference detection and `localStorage` persistence.
- 🌍 **Bilingual Support (EN / AR):** Dynamic language switcher with complete RTL (Right-to-Left) mirroring using modern CSS logical properties.
- ⚡ **Zero Framework Overhead:** Built purely with semantic HTML5, modern CSS3 (Custom Properties, Flexbox, Grid), and Vanilla JavaScript (ES6+).
- 📱 **Fully Responsive:** Perfectly adapts across all screen sizes (from 360px mobile up to 1440px+ ultra-wide screens) without horizontal scrolling.
- 🚀 **Production-Ready SEO:**
  - Rich OpenGraph (Facebook, WhatsApp, LinkedIn) and Twitter Card meta tags.
  - Schema.org JSON-LD structured data (`Person` & `WebSite` entities).
  - Preloaded critical LCP hero image, preconnected CDNs, `sitemap.xml`, and `robots.txt`.
- 🛠️ **Interactive Skills Section:** Infinite scrolling tech marquee, glassmorphism cards with pop-in animations, and a verified Codeforces badge.
- 💻 **Featured Projects Grid:** Equal-height responsive cards with live demo links, tag pills, and zero-layout-shift WebP image fallbacks.
- ⏳ **Experience Timeline:** Alternating vertical tree timeline with pulsing status badges for current roles.
- 📩 **Working Contact Form:** Powered by **Web3Forms** with client-side validation, anti-spam honeypot, and instant status notifications.
- ✉️ **Direct Gmail Popup:** Centered floating compose box (`680x650`) that allows visitors to write and send via Gmail without navigating away from the page.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/AlmaghrabyAli/Portfolio.git
```

### 2. Open the project
You can open `index.html` directly in any modern browser, or run a local lightweight server:

```bash
# Using VS Code Live Server extension (recommended)
# Or using Python:
python -m http.server 3000

# Or using Node.js:
npx serve .
```

Visit `http://localhost:3000` in your browser.
